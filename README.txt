पीक कापणी प्रयोग कॅल्क्युलेटर — PWA (GitHub Pages वर टाकण्याच्या सूचना)
=====================================================================

या फोल्डरमध्ये ४ गोष्टी आहेत:
  - index.html      (मुख्य अॅप)
  - manifest.json    (PWA माहिती + आयकॉन)
  - sw.js            (ऑफलाइन कॅशिंगसाठी service worker)
  - icons/           (192px, 512px, 180px आयकॉन)

GitHub Pages वर टाकण्याच्या पायऱ्या:
------------------------------------
1. github.com वर मोफत अकाउंट बनवा (नसल्यास).
2. नवीन Repository तयार करा (उदा. नाव: "pik-kapani-calculator"), Public ठेवा.
3. Repository उघडा -> "Add file" -> "Upload files" -> या फोल्डरमधील
   सर्व फाईल्स/फोल्डर्स (index.html, manifest.json, sw.js, icons फोल्डर सकट)
   ड्रॅग-ड्रॉप करा -> खाली "Commit changes" दाबा.
4. Repository च्या "Settings" टॅबमध्ये जा -> डाव्या बाजूला "Pages" निवडा.
5. "Branch" खाली "main" निवडून "Save" दाबा.
6. १-२ मिनिटांत तुम्हाला एक लिंक मिळेल, साधारण अशी:
   https://<तुमचे-username>.github.io/pik-kapani-calculator/
7. ती लिंक मोबाईल Chrome मध्ये उघडा -> आता वरच्या-उजव्या ⋮ मेनूमध्ये
   खरे "Install app" बटण दिसेल -> दाबून इन्स्टॉल करा.
   (आधीसारखा फक्त बुकमार्क नाही — ही खरी PWA इन्स्टॉल होईल, ऑफलाइनही चालेल.)

टीप: फाईल्समध्ये बदल केल्यास, तेच बदल पुन्हा GitHub वर अपलोड करा
(Upload files मधून, तीच नावाची फाईल बदलली जाईल).
